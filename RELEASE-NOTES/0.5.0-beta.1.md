This is a minor pre-release. HACS offers it only when you choose to show beta versions for this integration.

## Breaking change

- **Home Assistant 2026.7.0 or later is required.** The integration now opens serial ports through serialx, and older Home Assistant releases pin versions of serialx and aioesphomeapi that it cannot install alongside. Stay on 0.4.2 until you upgrade Home Assistant.

## New

- **Network serial ports.** You can set the integration up on a serial port that an ESPHome serial proxy shares over the network, such as the RS-232 port on a Home Assistant Connect AUX-2. Choose **Enter manually...** and enter a URL of the form `esphome://<host>:6053?port_name=<port name>`. This has not yet run against a real AUX-2, so reports on #3 are welcome.

## Changes

- **Serial ports open through serialx.** Home Assistant blocks pyserial-asyncio installs from 2026.7, so the integration now uses serialx, the library Home Assistant itself uses. Local serial ports work as before.

## Fixes

- **A binary sensor whose parameter never answers reports unknown, not off.** The signal poll also stops asking for a parameter that has never answered after three tries. On firmware 0.88 that saves about six seconds of every signal poll. Reloading the integration asks for every parameter again. Fixes #2.
